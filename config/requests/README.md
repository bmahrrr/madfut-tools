Custom team-build requests. The website creates these for you (Teams tab → "Build the most robust team",
or My Club compare → "Build a team to beat this team"). Each new file here starts a build on GitHub;
the result appears on the Teams tab under "Custom builds".

Format:
{"name": "Beat Reddit 79", "series": "79", "mode": "beat" | "robust", "minutes": 30,
 "opponents": [["id123", "id456", ... 11 card ids]]}
